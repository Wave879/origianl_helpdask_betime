# System Bug

Definition:
Application behavior or business logic is wrong even though the user action is valid.

When to use:
- Incorrect status transition
- Incorrect calculation
- Unexpected behavior
- Crash/exception caused by application logic
- Incorrect running number, sequence, registration number, or document number generated by the system even though the user followed the correct steps

When not to use:
- Feature request or intended new behavior
- User clicked the wrong record
- The user selected the wrong document, routed the wrong item, or registered the wrong record manually

Possible causes to check:
- Recent deploy
- Logic branch
- Data state that triggers the bug
- Steps to reproduce
- Sequence / numbering logic
