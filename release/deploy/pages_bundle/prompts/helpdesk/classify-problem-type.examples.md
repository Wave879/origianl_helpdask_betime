# Problem Type Examples

## Human error

Use when the user performed a wrong action or selected/received/routed the wrong item.

Common examples:

- กดรับเอกสารผิดเรื่อง
- ต้องคืนเลขรับ
- ลงรับผิดเลข
- ส่งเส้นทางหนังสือผิด
- ต้องแก้รายการที่ผู้ใช้เลือกผิด

## system error

Use when the system or server response failed.

Common examples:

- 500 error
- timeout
- server down
- failed to fetch
- endpoint ไม่ตอบสนอง

## System Bug

Use when the application logic behaves incorrectly even though the user action is valid.

Common examples:

- flow ทำงานผิด logic
- ข้อมูลแสดงผิดจาก logic
- กดถูกแล้วแต่ระบบไปสถานะผิด
- behavior ผิดปกติหลัง deploy
- เลขทะเบียนรับหนังสือขึ้นผิดเอง
- ระบบ generate เลขรับ / running number / sequence ผิด
- ผู้ใช้ทำขั้นตอนถูก แต่เลขเอกสารหรือเลขทะเบียนที่ระบบออกให้ไม่ถูกต้อง

## Change Request

Use when the request is to add, change, enhance, or adjust behavior by design.

Common examples:

- ขอเพิ่ม field
- ขอเพิ่ม dropdown
- ขอปรับ report
- ขอเพิ่มเงื่อนไขการทำงาน
- enhancement

## Software

Use for general app/data/auth/report issues that do not clearly fit the more specific categories.

Common examples:

- data mapping
- master data
- login/auth/session
- report/export issue

## network

Use for connectivity, VPN, LAN, Wi-Fi, or network route issues.

## hardware

Use for physical equipment such as printer, scanner, keyboard, mouse, monitor, or device issues.
